# Project skills

Skills in this directory are loaded by Claude Code on demand when relevant
to the task at hand (unlike `AGENTS.md`, which is always in context).

## Sourced from `everything-claude-code`

`nextjs-turbopack`, `postgres-patterns`, `database-migrations`,
`security-review`, `verification-loop` are copied, unmodified, from
[tpavanipradeep/everything-claude-code](https://github.com/tpavanipradeep/everything-claude-code)
(MIT licensed). That project ships 130+ skills covering many languages and
domains; these five were selected as the ones directly relevant to wacrm's
stack (Next.js, Supabase/Postgres, self-hosted API endpoints) — the rest
were left out to avoid bloating what Claude Code has to consider.
