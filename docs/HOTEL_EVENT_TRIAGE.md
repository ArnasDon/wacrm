# Event quotation intake

Hotel event inquiries ask whether the guest has a quotation number, has a quotation in progress, or wants a new quotation. Only an explicit new-quotation request continues AI intake. An ambiguous yes or a missing quotation number does not select the new path.

Existing quotations receive one acknowledgement and an internal reception handoff, with no generation, forms, catalog or reservation mutations. A teammate follows up within at most two hours during 08:00-20:00 in the account timezone; overnight the acknowledgement states business hours 08:00-20:00 instead of a two-hour deadline. Repeated pending follow-ups do not repeat the acknowledgement.

The account attention schedule, manual pauses, recent staff priority and operational payment/cancellation/human requests remain enforced. Villa San Ricardo continues to allow AI only from 20:00 to 08:00 America/Guatemala.
