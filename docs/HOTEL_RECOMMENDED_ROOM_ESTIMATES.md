# Price references for recommended rooms

When an eligible lodging reply recommends actual active room products and the pending request already has arrival, checkout and headcount but no chosen room, calculate a reference for the first priceable recommendation. Use the shared priceStay calculator and published nightly/seasonal rates. Do not select the room, change reservation details, seed its price or confirm a booking.

Skip incomplete or historical stays, multiple-room allocations, confirmed/selected requests, missing nightly rates, partial/over-capacity quotes and party splits the calculator cannot price. Do not replace staff quotes or special rates. Do not price a recommendation described as unavailable. Keep the existing schedule, staff ownership and operational routing.

Append the computed reference to the same guest-facing reply, the correct availability follow-up window and one room-selection question only if there is no question already. Avoid repeating an identical reference already in the transcript. This is a recommendation, not an availability guarantee or reservation confirmation.
