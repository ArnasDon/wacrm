Lo que dicen nuestros pacientes

Sobre este proyecto

Un CRM para WhatsApp construido para clínicas y equipos que viven en el chat. Más completo, más rápido, más tuyo.

Filosofía

  • → El CRM sirve al negocio, no al revés
  • → El tracking pertenece al visitante, no al contacto
  • → Los datos no se pierden: mergean identidades, no duplican
  • → Privacidad real: consent mode, CSP, sin PII en URLs

Lo que incluye (features)

  • ✓ Bandeja compartida WhatsApp (multi-agente)
  • ✓ Pipelines con estados configurables + scoring
  • ✓ Cola de Hoy 🔥⏳💤 (prioridad + urgencia)
  • ✓ Automatizaciones sin código (nodos visuales)
  • ✓ Broadcasts + plantillas Meta aprobadas
  • ✓ Llamadas Telnyx (WebRTC + grabaciones)
  • ✓ Email transaccional (Resend + webhooks)
  • ✓ Atribución completa (UTMs, click IDs, CTWA)
  • ✓ Reporting: campañas, canales, anuncios, perdidos

Roadmap (lo que viene)

  • 🔜 IA: resumen de hilos + respuesta sugerida
  • 🔜 CTWA end-to-end (captura clid + CAPI)
  • 🔜 Métricas de velocidad (Core Web Vitals)
  • 📦 Integración nativa Google Ads OCI / Meta CAPI
  • 📦 Marketplace de plantillas de automatización
  • 📦 Multi-clínica con facturación unificada
  • 🔬 Scoring predictivo con embeddings
